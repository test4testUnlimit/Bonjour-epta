# Bonjour epta

> Пишется **Bonjour**. Каталоги на диске (`~/.bonjur-epta`), имя
> репозитория и `BonjurLauncher.exe` сохраняют историческое написание
> без `o` — переименование осиротило бы уже сохранённые настройки,
> токены и словари, поэтому трогать их незачем.

Desktop-переводчик выделенного текста для Windows. Выделил мышью что угодно в любой
программе — рядом с курсором всплывает чип **«чивобля?»**, клик открывает окно с
исходником и переводом. Плюс горячая клавиша и словарь аббревиатур.

Интерфейс на русском. Языки перевода — любые.

## Privacy — прочитай до запуска

Программа по своей природе видит всё, что ты выделяешь мышью в любом окне. Что с этим
происходит:

| Что | Куда уходит |
|---|---|
| Выделенный текст | **Никуда**, пока ты не кликнул чип или не нажал хоткей. Захват идёт через UI Automation / native-сообщения окна, буфер обмена не трогается. |
| Текст, который ты отправил на перевод | На сервер выбранного провайдера. По умолчанию это **Google (gtx)** — то есть в Google. Провайдер меняется в настройках. |
| Лог `~/.bonjur-epta/bonjur.log` | Остаётся на диске. **Содержимое выделений в него не пишется** — только длины. Включить содержимое для отладки: переменная окружения `BONJUR_LOG_TEXT=1`. |
| Баг-репорты `~/.bonjur-epta/bugs/*.json` | Остаются на диске, никуда не отправляются. Содержат твоё описание и хвост лога. |
| Токен AI-шлюза | Только в памяти процесса. На диск не пишется, в лог не попадает. Закрыл программу — токена нет. |

Программа ставит **глобальные хуки клавиатуры и мыши** (пакеты `keyboard` и `mouse`) —
иначе она не узнает о выделении в чужом окне. На Windows это иногда требует запуска от
администратора. Она также периодически перечисляет запущенные процессы
(`app/peers.py`), чтобы понять, кто ещё дерётся за буфер обмена — это пишется в лог и
остаётся на машине.

Ничего не отправляется в интернет, кроме самого запроса на перевод и (если настроен)
запроса к AI-шлюзу.

## Запуск

```powershell
pip install -r requirements.txt
python main.py
```

Нужен Python 3.10+. Лаунчер (`launcher/`) ставит его сам при первом запуске.

## Как пользоваться

1. **Выдели текст** мышью (drag или double-click) → рядом с курсором чип «чивобля?» →
   клик открывает главное окно.
2. **Хоткей** (по умолчанию `Ctrl+Alt+E`, меняется в настройках) → сразу окно с
   переводом текущего выделения.

   Не вешай хоткей на `Alt`+букву без `Ctrl`: Windows отдаёт саму букву в активное
   окно на отпускании `Alt`, и она печатается поверх выделения.

Чип намеренно не всплывает, когда выделенный текст уже на языке, на который ты
переводишь — кроме случая, когда внутри нашлась аббревиатура из словаря.

## Как читается выделение

Без буфера обмена и без синтетического Ctrl+C:

1. Native-сообщения окна — `EM_GETSEL` + `WM_GETTEXT` для Edit/RichEdit. Сообщения
   выше `WM_USER` (`EM_EXGETSEL`, `EM_GETTEXTRANGE`, `SCI_GETSELTEXT`) остались как
   fallback, но между процессами они мертвы: `SendMessage` маршалит указатели только
   для системных сообщений ниже `WM_USER`.
2. UI Automation — `IUIAutomationTextPattern::GetSelection()` на отдельном STA-потоке
   с насосом сообщений. Chromium держит дерево доступности выключенным, пока его не
   спросят, поэтому пробник уходит уже на нажатии кнопки мыши — за время протяжки
   дерево успевает подняться.

Если оба пути молчат — чипа просто не будет. Это осознанный размен: пропущенный чип
лучше украденной вставки. Подделка Ctrl+C гонялась с ShareX, Caramba Switcher, AHK и с
твоим собственным копированием.

## API перевода

| Провайдер | Ключ | Статус |
|---|---|---|
| Google (gtx) | нет | **по умолчанию**, работает |
| MyMemory | нет (опц.) | работает, лимит ~500 символов |
| DeepL | да | готов, ждёт ключ |
| Yandex | да | готов, ждёт ключ |
| LibreTranslate | иногда | публичные инстансы нестабильны |
| DuckDuckGo | нет | экспериментальный |

## Словарь аббревиатур

`app/acronyms/data/*.json` — общеотраслевые термины, едут в репозитории.

Свои, рабочие — в `~/.bonjur-epta/packs/*.json`, они никогда не коммитятся.
Импорт таблицы из Confluence: `python scripts/import_confluence.py table.tsv --pack local`.
Классификатор пессимистичен: строка считается публичной только если доказала, что она
общеотраслевая, всё остальное остаётся локальным.

Названия своих площадок, продуктов и внутренних систем стоит перечислить в
`~/.bonjur-epta/internal_markers.json` — список пар `[метка, регулярка]`. Без него
строка вроде «process control at <твоя площадка>» может проскочить в публичные
кандидаты.

## AI-подсказки (опционально)

Если у тебя есть OpenAI-совместимый шлюз — положи его адрес в `~/.bonjur-epta/ai.json`
по образцу `ai.example.json`. Токен вставляется из буфера обмена: либо голый JWT, либо
`<tag>|<bearer>|<ms_token>|<refresh>`. Нет файла — все AI-кнопки серые, остальное
работает.

## Стек

- Python 3.10+, `customtkinter` — UI
- `httpx` — HTTP к API
- `keyboard` / `mouse` — глобальные хуки
- `ctypes` — UI Automation и native-сообщения окон (без зависимостей)
- C# лаунчер (`launcher/`) — установка Python и запуск
