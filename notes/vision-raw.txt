Вайб:
сделать онлайн переводчик выледенных слов в любой программи или браузерах с любого языка на любой (автодетект)

концепт внешнего вида:

главное окно при котрытии программы - основное, если открыта программа и с ней работают.

Типичный как у многих двухоконный интерфейс с вертикальной перегородкой между окнами посередине на которой есть кнопки (или возмоность их разместить позже)
В каждом окне схожий интерфейс выбора: 
автодетект языка ввода
выбор языка вывода перевода
кнопка - переключатель смены направления переводов (ru - en = en-ru) и результатов перевода

выбор API перевода (google deepl yandex DUCK DUCK GO и т.п.)
Кнопка перевести
кнопка вставить из буфера обмена
Api брать из надежных источников.
минимальный функционал:
перевод в главном окне по копипасте, по набору текста, по нажатию клавишиб по событию выделен текст - появляется иконка с текстом "чивобля?" кликая по которой появляется главное окно с результатами перевода и исходным текстом в соотвествующих окнах
